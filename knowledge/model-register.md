# Model register: concepts, Salesforce objects and their sources

Status: **draft 1, 11.10.2026, pending Lior's review.** Owner: Lior (Anna may edit, as for other master files).

One row per concept: the Salesforce object, the main relations, the source and the status. Read it before writing any statement about an object in a ticket, a sync file, a PR or a DD comment.

Rules:
- If a concept is not in this table, or your source says something different, do not decide it. Open a question Issue (`question.yml`) with the quotes.
- Rows marked **source conflict** or **open** are not settled. Do not build on them until Lior rules.
- Rows marked **Lior <date>** are decisions made after the DD was approved on 06.10.2026. For the Doc 1 and Doc 2 epics the approved DD still binds (see `dd/INDEX.md`); these rows mostly concern Doc 3 (events and finance), which is not in `dd/` yet.
- Record types are configuration, not objects. Do not add them as rows.
