## Definition (approved 18.11.2026)
- **Trigger:** on the 15th of every month, for next month (scheduled Apex); and a list view button on the "חודשי זמינות" tab that opens a screen with a month picker, the counts and a Run button, for any chosen month.
- **What it does:**
  1. Calls Hebcal once for the month (Israel schedule). Keeps only no-work holidays (`yomtov`), with their Hebrew name. If Hebcal fails, the run stops and creates nothing.
  2. Takes every active guide (`B25__Staff__c.B25__Is_Active__c`). Skips a guide who already has a record for that month (Month Key).
  3. Creates one Availability Month per guide (Staff, Year, Month) and fills each day. First match wins:
     1. Special Day of type חסום on that date: status יום חסום, no hours, note = the Special Day's Hebrew note, else its reason, else its name.
     2. Saturday or a Hebcal no-work holiday: status שבת/חג, no hours, note = the holiday's Hebrew name, else "שבת".
     3. A weekday of the guide's commitment (GoMeddo Availability on the Staff, not Unavailability, dates cover the day): status מחוייב, start = commitment start, duration = end minus start in half hours, capped at 9 (minimum 3).
     4. Anything else, Friday included: empty, for the guide to fill.
     A Special Day of type הערה only adds its note to the day.
  4. The screen shows, for the chosen month: active guides, months already built, missing; after Run: created and failed, with the reason.
- **Reads and writes:**
  - Reads `B25__Staff__c` (Id, Name, B25__Is_Active__c); `B25__Availability__c` (B25__Staff__c, B25__Days__c, B25__Start_Date__c, B25__End_Date__c, B25__Start_Hour__c, B25__Start_Minute__c, B25__End_Hour__c, B25__End_Minute__c, B25__Unavailability__c); `Special_Day__c` (Name, Date__c, Day_Type__c, Reason__c, Note_He__c); `Availability_Month__c.Month_Key__c`.
  - Writes `Availability_Month__c`: Staff__c, Year__c, Month__c, Day_NN__c, Day_NN_Start__c, Day_NN_Duration__c, Day_NN_Note__c.
- **Not in scope:** the email to guides and the form (A13-02); refreshing a month that already exists; the IDF unit soldier who is always available (A13-06); marking days as booked (A13-03); two time ranges per day (V13-09, open question).
- **Tool:** Apex, because it fills 124 fields by day number for several hundred guides and needs a callout; a Schedulable plus Queueable for the 15th (scheduled code cannot call out directly); an LWC in a screen flow, opened from a list view button, for the chosen month.
