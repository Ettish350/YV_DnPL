# D-010: A component belongs to the epic where it is enforced

| | |

| Date | 16.09.2026 |
| Challenges | none |

## Decision
A validation or automation belongs to the epic in which it is enforced, not the DD chapter where it is written. Result for the pilot: A1 owns A01-01, A01-11, A01-12, V01-02, V01-03; B1 owns V13-03, V13-05, V13-07 (fields only; enforcement in B3), A13-08. The rest go to C1, A3, B2, B3, B5, X1 as listed in brief section 7.

## DD source / evidence
Doc 2 validation and automation tables of chapters 'בניית מוצרים...' and 'זמינות מדריכים...'.

## Alternatives considered
Assign by chapter: A1 would contain order-time automations that cannot be tested without C1.

## Affects
Brief 7. All A1 and B1 tickets.
